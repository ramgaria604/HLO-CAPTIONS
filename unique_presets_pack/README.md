# Unique Presets Pack (26 styles)
Put this folder in your project, then give ANTIGRAVITY_COMMAND.md to Antigravity (STEP A).
Each style has its own idea (different motion and layout), made with SVG + CSS only. Add your own by copying one block in src/UniqueCaptions.tsx.
Styles: Ink & Scribble, Rainbow Wave, Ransom Cut-outs, Breaking News Bar, Flickering Neon Sign, RGB Glitch, Comic Burst, Terminal Typewriter, Karaoke Sweep, Pop Highlight Box, Rubber Squash, Cinema Serif, Sticker Words, Chalkboard, Retro Arcade, Mirror Floor, Gooey Liquid, Spotlight, Highlighter Swipe, Chat Bubble, Fill-Up Outline, 3D Anaglyph, Unfurling Ribbon, Emoji Reactor, Poster Cascade, Aurora Glass Pill.
